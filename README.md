# Python Calculator

My first Python project, built from scratch while learning programming.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Decimal number support
- Division by zero handling
- Invalid operator handling
- Continuous calculations
- Input validation using try/except

## Concepts Learned
- Variables and data types
- Conditional statements
- Loops
- Functions
- Return values
- Exception handling

## How to Run

1. Install Python.
2. Clone this repository.
3. Run:

   python calculator.py
